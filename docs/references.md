# References and Provenance

TideRefresh is an original Swift implementation. These projects informed the
behavioral design; they are not runtime dependencies:

- [MJRefresh 3.7.9](https://github.com/CoderMJLee/MJRefresh/tree/3.7.9): scroll boundaries and header/footer behavior.
- [ESPullToRefresh](https://github.com/eggswift/pull-to-refresh): animator protocols.
- [CRRefresh](https://github.com/CRAnimation/CRRefresh): customizable presentation.
- [KafkaRefresh](https://github.com/BeatsKitano/KafkaRefresh): completion/retry presentation.
- [UIScrollView-InfiniteScroll](https://github.com/pronebird/UIScrollView-InfiniteScroll): distance-based prefetch.

No source files, image assets or substantial code excerpts were copied from these
repositories. Future reuse must retain the original copyright and license notice.
